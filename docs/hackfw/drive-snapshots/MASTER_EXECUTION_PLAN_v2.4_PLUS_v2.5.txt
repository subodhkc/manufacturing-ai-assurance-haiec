27.1 North star and UX structure
“Detect → Investigate → Authorize → Contain → Verify → Report.” Each step has: (1) exact source mode and snapshot, (2) what the operator can see, (3) what the platform has actually established, (4) next permissible action, (5) missing evidence or owner. Operator flow opens from the manufacturing Executive Command Center and direct sidebar; the 9-system Assurance page, existing 60-second Replay and sample Master Report remain source owners. Do not create a second scoring or assurance engine. Clear UX differentiation: dark/green provenance “PERSISTED HAIEC · SYNTHETIC LAB”; amber “SIMULATED RESPONSE · BROWSER ONLY”; neutral “NOT ESTABLISHED / NOT ASSESSED”. The response interaction is a demonstration fixture, not a historical response to the stored finding.

27.3 Six-step UI contract and meaningful interactions
1 DETECT — authoritative rule ID, predicate status, evaluation ID, source-class banner, exact target. Link to canonical case. Never turn MATCH green.
2 INVESTIGATE — before/after target comparison, source record lineage, requested/approved/granted/code/observed evidence coverage and first known divergence. A historical rule's reason is not a proven root cause.
3 AUTHORIZE — show the exact current action envelope and distinguish documented pre-action approval from new incident-response permission. Browser may present a proposed authorized containment; it may not issue a HAIEC delegation artifact. Approval absent => NOT ESTABLISHED. Owners: Quality Supervisor / Plant Quality Manager as specified by bounded policy.
4 CONTAIN — a deliberate “Pause simulated dispatcher” control affects ONLY isolated in-memory Station 217 fictional operations; the UI visibly says it is not HAIEC's live kill switch. A local “Attempt request after pause” demonstrates a simulated denied dispatch with its own local, non-authoritative trace. No PLC/MES/QMS writes, no production kill-switch endpoint or credentials.
5 VERIFY — render two evidence columns: historical R01 effect-witness SATISFIED (actual synthetic wrong-target effect) and response-block verification NOT ESTABLISHED. Never inherit the R01 receipt into the simulated response. A native independent post-control witness is needed before live-effect claims. Distinguish command issued, guard enforced, blocked attempt, native readback and safe recovery.
6 REPORT — link canonical digest-verified case, public SYS-217 sample and read-only replay; export/print of contextual report view only, not a newly issued signed Master Report. Report states unresolved evidence and next owner.
